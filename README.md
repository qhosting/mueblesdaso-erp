# Ejecutar y desplegar tu aplicación

Esto contiene todo lo que necesitas para ejecutar tu aplicación localmente.

Ver tu aplicación en AI Studio: https://ai.studio/apps/drive/1ADL0sc7EjjE0TuSMp2WN-CpNks0RL8mJ

## Ejecutar Localmente

**Prerrequisitos:** Node.js

1. Instalar dependencias:
   `npm install`
2. Configura la `GEMINI_API_KEY` en [.env.local](.env.local) con tu clave API de Gemini
3. Ejecutar la aplicación:
   `npm run dev`
